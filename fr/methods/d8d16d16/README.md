## D8/D16/D16

Lancez un D8 et deux D16. L'indice est `(D8 - 1) × 256 + (premier D16 - 1) × 16 + (second D16 - 1)`. Chaque série sélectionne un indice ; consultez la [table complète](../../../methods/d8ff/).
