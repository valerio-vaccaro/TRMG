## D8/D16/D16

Dobj egy D8-cal és két D16-tal. Az index: `(D8 - 1) × 256 + (első D16 - 1) × 16 + (második D16 - 1)`. Minden sorozat indexet választ; lásd a [teljes táblázatot](../../../methods/d8ff/).
