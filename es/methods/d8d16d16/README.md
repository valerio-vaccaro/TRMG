## D8/D16/D16

Lanza un D8 y dos D16. El índice es `(D8 - 1) × 256 + (primer D16 - 1) × 16 + (segundo D16 - 1)`. Cada serie selecciona directamente un índice; consulta la [tabla completa](../../../methods/d8ff/).
