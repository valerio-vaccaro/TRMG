## D8/D16/D16

Бросьте один D8 и два D16. Индекс: `(D8 - 1) × 256 + (первый D16 - 1) × 16 + (второй D16 - 1)`. Каждая серия выбирает индекс; см. [полную таблицу](../../../methods/d8ff/).
