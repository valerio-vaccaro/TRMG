## Создайте фразу восстановления монетой

Каждый бросок даёт один бит. Сделайте 11 бросков для каждого предварительного слова, повторите для 12 или 24 слов, затем следуйте [процедуре последнего слова](../../#исправьте-последнее-слово).

|Результат|Бит|
|------|---|
|Орёл|0|
|Решка|1|

Читайте биты слева направо и используйте [двоичную таблицу слов](../../../tables/binary-table/).
