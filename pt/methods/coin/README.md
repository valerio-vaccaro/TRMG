## Gere uma frase de recuperação com uma moeda

Cada lançamento fornece um bit. Faça 11 lançamentos para cada palavra provisória, repita para 12 ou 24 palavras e siga o [procedimento da última palavra](../../#corrigir-a-ultima-palavra).

|Resultado|Bit|
|------|---|
|Cara|0|
|Coroa|1|

Leia os resultados da esquerda para a direita e use a [tabela binária de palavras](../../../tables/binary-table/).
