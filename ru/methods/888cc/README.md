## D8/D8/D8/монета/монета

Бросьте три D8 и две монеты. Орёл — `0`, решка — `1`. Индекс: `(первый D8 - 1) × 256 + (второй D8 - 1) × 32 + (третий D8 - 1) × 4 + первая монета × 2 + вторая монета`; см. [полную таблицу](../../../methods/888cc/).
