## D8/D16/D16

Wirf einen D8 und zwei D16. Der Index ist `(D8 - 1) × 256 + (erster D16 - 1) × 16 + (zweiter D16 - 1)`. Jede Serie wählt einen Index; siehe [vollständige Tabelle](../../../methods/d8ff/).
