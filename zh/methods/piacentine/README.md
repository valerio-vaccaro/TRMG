## 皮亚琴察牌

使用 40 张皮亚琴察牌。根据[牌面映射表](../../../methods/piacentine/)收集 11 位；每次抽取后放回并洗牌。

## 完整流程
1. 按本页规则取得11位。
2. 按顺序记录比特。
3. 在链接表中查找英文BIP-39词。
4. 重复至12或24个临时词。
5. 校正最后一个词。
