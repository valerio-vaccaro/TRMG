## D8/D16/D16

Lance um D8 e dois D16. O índice é `(D8 - 1) × 256 + (primeiro D16 - 1) × 16 + (segundo D16 - 1)`. Cada série seleciona um índice; consulte a [tabela completa](../../../methods/d8ff/).
