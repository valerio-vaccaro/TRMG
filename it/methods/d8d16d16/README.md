## D8/D16/D16

Lancia un D8 e due D16. L'indice è `(D8 - 1) × 256 + (primo D16 - 1) × 16 + (secondo D16 - 1)`. Ogni serie seleziona un indice; consulta la [tabella completa](../../../methods/d8ff/).
