## 用皮亚琴察牌生成恢复短语

使用一副 40 张的皮亚琴察牌。每张牌提供比特；每个词收集 11 位，重复 12 或 24 次，然后遵循[最后一个词的步骤](../../#校正最后一个词)。

|1024|512|256|128|64|32|16|8|4|2|1|索引|词语|
|----|---|---|---|--|--|--|-|-|-|-|-----|----|
|    |   |   |   |  |  |  | | | | |     |    |

|1024|512|256|128|64|32|16|8|4|2|1|索引|词语|
|----|---|---|---|--|--|--|-|-|-|-|-----|----|
|1   |0  |1  |1  |0 |0 |0 |1|0|1|0|     |    |

使用[二进制词语表](../../../tables/binary-table/)查找词语。
