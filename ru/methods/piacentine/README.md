## Создайте фразу восстановления пьячентинскими картами

Используйте колоду Piacentine из 40 карт. Каждая карта даёт биты; наберите 11 на слово, повторите для 12 или 24 слов, затем следуйте [процедуре последнего слова](../../#исправьте-последнее-слово).

|1024|512|256|128|64|32|16|8|4|2|1|Индекс|Слово|
|----|---|---|---|--|--|--|-|-|-|-|-----|----|
|    |   |   |   |  |  |  | | | | |     |    |

|1024|512|256|128|64|32|16|8|4|2|1|Индекс|Слово|
|----|---|---|---|--|--|--|-|-|-|-|-----|----|
|1   |0  |1  |1  |0 |0 |0 |1|0|1|0|     |    |

Используйте [двоичную таблицу слов](../../../tables/binary-table/).
